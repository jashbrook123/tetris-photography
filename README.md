My photography coursework entails placing video game sprites over real life images.

I want to take this one step further and create an exhibition piece, a playable version.

Importing the back end of the ISO-Tetris game, I have put it on any image wanted.

**Step 1**

Drop any image saved locally into the screen created from running screen_grab.py

**Step 2**

Using the number keys _1_ - _4_, you click 4 times to define the warped rectangle where you want this surface to be placed.

**Step 3**

Either using **WASD** or **ARROWS** to control the pieces, and double *DOWN* leads to a quickdrop.

*Space* is used to hold a piece
